## Project Description

The Supermarket Sales Intelligence Dashboard is a Python-based data analytics project built using Streamlit. It helps users explore supermarket sales data through an interactive dashboard.

The project uses a sample dataset to demonstrate how sales information can be organized, analyzed, and visualized.

## Project Objectives

- Explore supermarket sales data.
- View sales information using interactive charts and summaries.
- Analyze sales across available categories, such as branches, products, and payment methods.
- Practice data analysis and visualization using Python.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Matplotlib

## Dataset

The project uses a **synthetic sample dataset** containing 500 rows of supermarket sales information.

It includes fields such as invoice ID, date, branch, city, product, customer type, quantity, unit price, sales, payment method, and rating.

The dataset is included in this repository as:

[`Supermarket.csv`](Supermarket.csv)

**Note:** This is generated sample data, not real supermarket transaction data.

## Setup and Run Instructions

### 1. Install Python

Install Python 3.12 or another compatible Python version.

### 2. Download the project

Download or clone this repository and open the project folder in a terminal.

### 3. Create and activate a virtual environment (Windows PowerShell)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 5. Run the dashboard

```powershell
python -m streamlit run AkankshaGaneshGhorpade_SupermarketSalesIntelligence.py
```

Streamlit will display a local URL in the terminal. Open that URL in your browser to view the dashboard.

Keep the terminal running while using the dashboard. Press `Ctrl+C` in the terminal to stop it.

## How to Use

1. Start the Streamlit application.
2. Open the local URL shown in the terminal.
3. Explore the dashboard and its available charts, summaries, and filters.
